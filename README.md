# Digital Clock (Java)

## Description

This is a simple digital clock made using Java. It displays the current time and updates it every second.

## Features

- Shows current time
- Updates every second
- Simple console program

## Technologies Used

- Java
- LocalTime
- DateTimeFormatter

## How to Run

Compile:

javac DigitalClock.java

Run:

java DigitalClock

## Output

===== DIGITAL CLOCK =====

Current Time: 18:30:01
Current Time: 18:30:02
Current Time: 18:30:03
